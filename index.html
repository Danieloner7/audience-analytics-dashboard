The Problem

A mid-sized media organization operating radio, television, and online publication channels collected audience data from five completely disconnected platforms — broadcast ratings, Google Analytics, Facebook, Instagram, and YouTube. Staff spent 2–4 hours every week manually compiling reports, leading to delayed editorial decisions, inconsistent metrics, and weak advertiser confidence.

The Solution

A centralized Audience Analytics Dashboard built with Google Looker Studio, integrating live data from all five platforms via API connectors. The system automatically computes five key performance indicators, supports dynamic date range and platform filtering, enforces role-based access control, and generates professional PDF advertiser reports — all at zero licensing cost.

System Architecture

The system follows a four-layer pipeline architecture. Data flows unidirectionally from sources through the connector and processing layers to the access-controlled dashboard UI. Each layer is independently modifiable — adding a new platform connector requires no changes to existing modules.
