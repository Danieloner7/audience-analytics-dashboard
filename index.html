The Problem

A mid-sized media organization operating radio, television, and online publication channels collected audience data from five disconnected platforms — broadcast ratings, Google Analytics, Facebook, Instagram, and YouTube. Staff spent 2–4 hours weekly manually compiling reports, leading to delayed decisions, inconsistent metrics, and weak advertiser confidence.

The Solution

A centralized Audience Analytics Dashboard built with Google Looker Studio, integrating live data from all five platforms via API connectors. The system automatically computes five key performance indicators, supports dynamic filtering by date range and content type, and generates professional PDF advertiser reports — all at zero licensing cost.
